# Brick by Script

Build interiors, write scripts, and work on clothing, jewelry and vehicles in one Windows workspace.

## Download for Windows x64

[Download Brick by Script 0.21.0](https://github.com/404hxlo/brick-by-script/releases/download/v0.21.0/Brick-by-Script-0.21.0-Setup.exe)

Already using 0.18.0 or later? Open **Workspace settings → App updates**, enable **Include preview releases**, then check, download and choose **Install and restart**. Earlier versions need one manual installation to gain the updater.

[Release notes, checksums and optional installer + examples ZIP](https://github.com/404hxlo/brick-by-script/releases/tag/v0.21.0). Extract the ZIP before running its installer. GitHub's automatically generated source archives are not the app installer.

## New in 0.21.0

- **18 practical studio lessons.** Clothing, Jewelry, MLO, Vehicle, Script and Pack Builder paths explain the concepts, guide a task, show expected results and check understanding. The eleven existing Lua lessons remain available.
- **Practice beside your project.** Pin a collapsible lesson, record the steps you tried and return for a knowledge check. Progress resumes on this PC and never locks studio features.
- **Find the tools and models.** Learn → Tools & models includes studio filters, official or developer-linked downloads, the installed-tool checker, and male/female GTA character preparation from your own Legacy installation. No redistributed game-model downloads are bundled.
- **Learn outside the app.** Both the website and documentation include the new learning paths and setup guide.

[Learning paths](https://404hxlo.github.io/brick-by-script/docs/learning-paths/) · [Tools and character setup](https://404hxlo.github.io/brick-by-script/docs/tools-and-models/)

## Explore the studios

- Script, MLO, Clothing, Jewelry and Vehicle studios, with beginner guidance and advanced tool workflows.
- Real male/female GTA fitting character setup using your own GTA V Legacy installation, Blender with Sollumz and CodeWalker. No need to locate a wearable GLB first. Game models are not included in the download; another PC needs its own setup.
- Project folders, tags, favorites, duplication, recoverable Trash and recovery checkpoints.
- Optional GitHub accounts and private project snapshots. Save a chosen project to cloud and get a separate local copy on another PC. This is not automatic sync or simultaneous editing. Local editing needs no account.
- Project backups and transfer bundles for moving editable work and supported linked sources.

The cloud preview allows 512 MiB of reserved snapshot storage per account, including older versions and unfinished transfers. See the [cloud guide](https://404hxlo.github.io/brick-by-script/docs/cloud-projects/).

## Alpha limits

This is an **unsigned Windows alpha**. Clean-device/laptop acceptance and actual FiveM gameplay testing remain pending. Native exports need compatible assets and tools; custom clothing can still need manual Blender/Sollumz preparation. UI tests do not establish in-game collision, rigging or animation behavior. See the release notes for this candidate's completed checks.

Custom imported GLBs may need their original files relinked after changing targets and using Undo. Character caches are local to each PC and are not included in project backups or cloud snapshots.
