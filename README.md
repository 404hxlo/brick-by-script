# Brick by Script

Build a FiveM interior or write your first Lua command in an offline Windows workspace. Draw rooms on a floor plan, inspect them in 3D, and keep an editable copy of each project on your computer.

## Install on Windows x64

[Get the Windows beta and examples](https://github.com/404hxlo/brick-by-script/releases/tag/v0.8.6)

Open **Releases**, choose **Brick by Script 0.8.6**, and expand **Assets**. For a first install, download `Brick-by-Script-0.8.6-Windows-x64.zip`. In File Explorer, choose **Extract All**, then open **Brick by Script 0.8.6 Setup.exe**. The ZIP includes an editable two-room house, a prebuilt FiveM resource, a welcome script, and a walkthrough.

For an existing installation, close Brick by Script and run `Brick-by-Script-0.8.6-Setup.exe`. Upgrading from 0.8.5 preserves projects saved under the same Windows account.

## Try the app

- **Move a doorway.** Choose **Getting started → Open example house → Edit the example house**. Select the living room, move its front door, and inspect the change in 3D.
- **Write a command.** Choose **Getting started → Make a chat command**, change the greeting, then type `/hello` in the simulated chat.
- **Move your work to a laptop.** Choose **Getting started → Your projects → Save project backup…**, transfer the `.brickbyscript` file, then choose **Open project backup…** on the other computer.

## Native map builds

Both demos run offline. Rebuilding an edited interior for GTA V Legacy requires Blender, Sollumz, and its compatible native export provider. For a development server, the complete ZIP includes `two-room-house.zip` and `WALKTHROUGH.md` with the sample location and in-game checks.

Version 0.8.6 is an unsigned Windows beta. Automated tests verified native resource generation. Clean-machine installation and the in-game walkthrough remain pending.
