What’s new in 0.20.2

Browse existing resource files and change clothing targets with clearer controls, preserved artwork and Undo.

0.20.2 — Find your files. Keep creating.#

  • Browse your own files: Add resource file now opens the Windows file picker through Browse files…. Select an existing text file, review its project destination and add its contents. Existing paths are protected; your original file stays unchanged.
  • Keep text intact: imports and editor changes preserve Unicode, existing UTF-8 byte-order marks and line endings. Cancelling the picker keeps your current selection; Use empty file returns the dialog to blank-file creation.
  • A clothing button that opens the browser: Edit GTA clothing… now starts the GTA item browser directly and reveals the choices beneath the preview.
  • Change the fitting target: Item type, Fitting body and the custom GTA slot can be changed after loading a garment. A confirmation explains what will be unlinked. Your text and logos stay, and Undo restores the previous design.
  • Keep the preview in step: changing targets clears the old model instead of leaving the previous garment visible. Loading briefly disables these controls to prevent overlapping requests.

Changing a target selects a different workflow; it does not convert the old mesh into another body or item. Choose a matching garment and review your artwork’s placement. Custom GLB previews may need their original files relinked after Undo. Source files are not deleted.

Follow Add a file from your computer or Change the body or item type.

0.20.1 — Start with the character you will use#

Clothing Studio now begins with a guided Set up GTA character flow for the real male and female freemode bodies. The old bundled fitting person no longer appears in this workspace.

  • No GLB hunt: choose your GTA V Legacy installation and use the existing Blender/Sollumz and CodeWalker pipeline to prepare the character locally.
  • Prepare once per body: Studio keeps the prepared model in this PC's app profile. Use it in a new top design by selecting Set up GTA character. Saved projects created through setup can restore their character automatically.
  • Keep custom garments yours: setup does not silently replace original garment designs, custom GLB bindings, jackets or other clothing categories with a default tee. Existing GLB and component imports remain available.
  • Keep creating without a character: original shirt and hoodie patterns remain available as a garment-only workspace.

Game assets are not included in the installer or project backups. Another PC needs its own game installation and character setup. Blender with Sollumz and CodeWalker are still required for first-time preparation. See the character setup steps and creative tool setup.

0.20.0 — Make room for your next idea#

Midnight Showroom brings the blue Brick by Script identity into the working desktop app, with navy panels, clearer navigation and a gallery of your own saved work. All five studios and your existing local project library remain available.

  • A shared top bar: use Home, Projects, Studios, Tools and Learn, with command search and settings alongside them. Home and the project library share a New project chooser for all five project types.
  • Resume with a real preview: Home shows the current project and recent work. Previews come from supported saved app viewports and stay in a bounded local cache. They do not upload source assets or become project backups.
  • A clearer project library: browse a gallery, filter by studio or folder, and keep favorites, tags, selection, context menus, recoverable Trash and recovery actions.
  • Settings that stay organized: a category sidebar, live workspace preview and reachable Done button keep layout, editor, recovery, tool, account and update controls together. Preferences persist across restarts.
  • Consistent studio surfaces: darker panels and a calmer vehicle stage use the same theme without changing imported geometry or paint.
  • Safer everyday details: editing shortcuts do not act on a model while focus is inside the new navigation menus. Notifications and menus are excluded from saved preview captures; favorite, rename and organization actions retain an unchanged project’s preview.

Start with the new navigation, saved project previews or workspace settings. Beginner examples and backup commands remain on Home below the recent-project gallery.

0.19.3 — Protect the work you just did#

This update fixes reliability problems found in an audit and checked again by different reviewers. It keeps the editing tools introduced in earlier versions while improving how the app handles delayed work, recovery and everyday controls.

  • Keep newer edits: delayed MLO imports and completed fitting saves preserve changes made while the operation was running. Imports cannot replace another project's scene, and Undo returns to the actual scene before the import.
  • Keep results tied to their source: MLO builds and design proposals identify the saved scene used. Mesh results check their source and calculation settings; walkthrough exports check the requesting project.
  • Recover intact work: a valid checkpoint can restore a new copy even when the latest project record is damaged. The original stays unchanged, and invalid checkpoints are still rejected.
  • Avoid stale output replacements: competing exports to one destination no longer silently replace each other's completed files.
  • Edit collisions consistently: primitive-only scenes keep their valid format, and generated architectural objects support collision authoring.
  • Use everyday controls more comfortably: dialogs focus their intended fields, library search regains typing focus after initial loading, open dialogs block global project shortcuts, and keyboard-selected palette commands scroll into view.

Read recover a damaged project, MLO background results and dialogs and commands for practical guidance.

0.19.2 — Pick up where you left off#

Reopen a project with its tabs, active file, text selection, cursor, editor scroll and last project workspace restored. These navigation preferences stay on this computer and survive restarting the app. Save your project normally; navigation metadata is not a backup or a cloud upload.

Use arrow keys, Home/End and type-ahead in Explorer. Shift-click or Shift+arrow selects project ranges, Ctrl-click toggles a project, and Ctrl+A selects the visible list while it has focus. Text fields retain normal text selection.

Right-click visible MLO geometry, vehicle parts and imported jewelry meshes for their existing actions. Right-drag still controls the camera. Blank space offers applicable frame/show-all actions. Vehicle visibility is preview-only; hidden imported jewelry parts affect its supported export.

Search now reaches beyond 100 results with Previous/Next. Library Refresh/Retry, Clear filters, Clear selection and named Trash confirmation make the scope of your next action clearer. Dialog titles are accessible, and protected manifest actions are disabled before an invalid operation.

Read resume and navigate and select project ranges.

0.19.1 — Keep useful actions within reach#

Right-click a project, script file or folder to see the actions for that item. Library actions include opening, renaming, duplication, favorites, folder/tags, recovery and recoverable Trash. Explorer keeps New file, relative-path copying and file management close to the selected row.

The code editor has Cut, Copy and Paste. Normal text fields provide native text-editing menus. File tabs can close individually, close others, close to the right or close together, then reopen from session history. Use Ctrl+W, Ctrl+Shift+T and Ctrl+Tab, or middle-click a tab. Closing a file tab preserves its unsaved text.

MLO hierarchy menus expose framing, duplication, copy/paste, grouping, visibility, locking, isolation and deletion confirmation. Clothing artwork layers provide duplication, copy/paste, ordering and visibility. Imported jewelry parts can be hidden from both the model and export; Vehicle Studio part menus control preview visibility.

Focus a supported row and press Shift+F10 or the Menu key to open its menu. Arrow keys move between available actions; Escape dismisses it. Read everyday Script Studio editing and project actions.

0.19.0 — Your workspace, on your terms#

The settings screen now uses the app’s blue blueprint design. Arrange workspace panels with an immediate preview, change editor preferences and find recovery, tools, accounts and updates in clearly separated sections. Read Make the workspace yours.

Optional GitHub sign-in adds private cloud snapshots: save a chosen project, then download an independent local copy using the same account on another PC. Conflicting saves are blocked so you can review both copies. You control uploads, cloud-project deletion and cleanup of interrupted transfers. This is explicit snapshot transfer, not automatic sync.

The preview has a 512 MiB reserved-storage allowance per account, including older versions. Local editing remains available without an account. See Continue on another PC for the full workflow and limits.

0.18.0 — Update without leaving the app#

Open App updates from Workspace settings or the command palette. Check for a newer release, read its notes, download with progress and cancellation, then choose Install and restart when you are ready.

Downloads are checked against the published size and SHA-256 before installation. Optional startup checks never download or install automatically. Choose whether to include preview releases, and use clear retry messages for offline access, rate limits or failed downloads.

The installed Windows x64 app supports installation; portable and development copies explain that the setup installation is required. Older releases need one manual installer update to gain this feature. See Update the app.

0.17.1 — More control over your projects#

Open Project library with Ctrl+O to rename, duplicate, favorite, tag and organize designs with folder labels. Search and filter across studios, then sort by name or recent activity.

Move one or several projects to recoverable Trash and restore them later. Dependency checks protect collections and server jobs that still use a project. A project copy keeps the current editor active until you open the new copy. See project management.

Keep useful versions and reuse your edits#

  • Name and pin recovery checkpoints. Library recovery restores the selected project’s saved revision as a new copy.
  • Use Save / Discard / Cancel when switching or closing with autosave off, or explicitly discard unsaved edits from the command palette.
  • Rename, move, duplicate and remove script files or folders through Explorer. Removal creates a checkpoint first.
  • Keep Clothing and Jewelry Undo when visiting another workspace during the same app session.
  • Duplicate a clothing artwork layer, or copy and paste it into another design.
  • Switch jewelry types without losing each type’s dimensions and fitting settings. Reset dimensions leaves attachment and placement intact.

Start with Recover work and use Undo or the script file controls.

More clothing and jewelry starting points#

The 0.17.0 expansion is included in this release. Clothing Studio adds category-based workflows for pants, shoes, boots, hats, helmets, glasses, goggles, masks and other wearables alongside tops. Non-top categories start from a matching permitted source mesh; selecting a category does not generate every possible garment.

Jewelry Studio adds editable watches, bracelets, rings, grills and earrings alongside necklaces and pendants. Use dimension and attachment controls, then inspect the fit. Read the clothing guide and jewelry guide for the actual source and export requirements.

What is tested, and what still needs checking#

See the 0.20.2 release notes for the checks performed on the exact downloadable build. File browsing, text preservation, target changes, cancellation, Undo and reopening are separate checks from native asset conversion or gameplay.

The earlier 0.20.0 development and packaged desktop walkthroughs covered all five creation choices, navigation, context menus, saved previews, settings persistence, project reopening and source-file integrity using isolated projects. Those historical results are not a claim that every workflow was retested for this update.

The app remains an unsigned alpha. This update does not establish clean-laptop, hosted sign-in, cross-device transfer or FiveM gameplay acceptance. Test the final exported resource in FiveM before relying on it.

Get the current public alpha#

On an updater-enabled installation, follow Update the app. Otherwise download the Windows installer, save your work, close the older app and run the installer. Follow Install on Windows for setup and verification. The GitHub release includes the published notes and checksums.
