Your first project

Move a doorway in the example house, inspect it in 3D and reopen your saved work.

Start with the example house#

This exercise makes one visible change to an existing project. You will move a front door, inspect the change in 3D and save the editable house. It works without a FiveM server.

  1. Open Getting started.
  2. Choose Open example house.
  3. Choose Edit the example house to begin the guided tour. If you previously paused it, the control may say Resume example house tour.

Follow the highlighted controls in the app. The tour uses the example’s rooms and openings, so begin with the supplied house rather than an unrelated project.

Move the doorway in the floor plan#

  1. Open Floor plan to see the rooms from above.
  2. Select the room named by the tour, either on the plan or in the Room menu.
  3. Under Openings, choose the door identified by the tour.
  4. Change Opening offset to slide the door along its wall. Use the suggested value and press Enter.

Expected result: the opening moves along the selected wall. An offset describes where the opening sits on that wall; it does not change the whole room’s position. If the new location does not fit, choose a smaller valid offset and inspect the plan again.

Check the change and save it#

  1. Open Scene view.
  2. In Perspective view, choose Frame selection or scene. Drag an empty part of the viewport to orbit around the doorway.
  3. Save your edited house. Wait until the app reports the saved state.
  4. Return to Getting started → Your projects → Browse project library and reopen your saved copy.

Expected result: the reopened house keeps your new doorway position. You have completed an editable project, not an in-game acceptance test. Continue with a project backup before experimenting further.

Prefer a first coding task?#

Choose Getting started → Make a chat command. Change the greeting inside its quotes, then enter /hello in the simulated chat. The Script Studio guide takes you through that workflow.
