Set up Blender and Sollumz

Check the external tools used for native assets and move between an editable source and the app's preview.

What each tool does#

Brick by Script provides the project workspace and beginner-facing tools. Blender supplies detailed modeling and source-file editing. Sollumz adds the GTA-oriented asset workflow inside Blender. CodeWalker is used for supported asset inspection or conversion steps where that workflow requires it.

You can learn the core editors without completing every native-tool setup first. Producing your own native game asset is the point where the selected pipeline's dependencies matter.

Check your installation#

  1. Install Blender and follow the official Sollumz setup documentation for a compatible combination. Enable the add-on and any native export provider required by your chosen workflow.
  2. In MLO Studio, open Blender tools, or use Build and test → Check build tools.
  3. Read the Blender and GTA tools results. If the intended Blender installation was not detected, choose Choose blender.exe.
  4. After changing the installation or add-ons, select Check again. Resolve the specific issue shown before trying a native build.

The tool check reports detected versions and availability. Keep that information with a build report so a later failure can be compared with the tool combination that produced the earlier result.

Keep source and preview in sync#

In MLO Studio, Export Blender source creates an editable Blender source. The result offers Continue in Blender. A saved .blend is source work, not a finished FiveM resource.

In Clothing Studio, use the Blender workspace. Create Blender source… prepares the selected input; Open in Blender lets you edit it; Refresh from Blender reads the saved result. When importing GTA clothing through Sollumz, the workspace requests the local YDD with its matching skeleton YFT, and a YTD when textures are needed.

Vehicle Studio uses Native workshop with Create .blend from YFT… or Link vehicle .blend…. Save changes in Blender before refreshing the app's model.

Use CodeWalker when needed#

The GTA tools dialog includes Choose CodeWalker, Open CodeWalker and Convert native / XML. Follow the supported conversion result and instructions for your specific files. Merely renaming JSON, XML or a generic mesh to a GTA extension does not convert the asset.

Keep source files and referenced textures together when moving projects. See projects and backups, then review the export checklist before packaging.
