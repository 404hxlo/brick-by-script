Welcome to Brick by Script

Find your starting point, understand the studios and make your first small change.

One workspace for your next idea#

Brick by Script is a Windows desktop workspace for FiveM creators. Use Script Studio to work on Lua resources and interfaces, or MLO Studio to build an editable interior. Clothing, Jewelry and Vehicle studios provide workspaces for supported wearable and vehicle workflows.

You do not need to understand every tool before you begin. Start with one task: move a doorway in the example house or change a greeting in the guided chat project. Core editing and these practice activities work offline.

Find your way around the new workspace#

The top bar is shared across the app. Home resumes your current project and shows recent work. Projects opens the local library. Studios switches between Script, MLO, Clothing, Jewelry and Vehicle studios. Tools keeps the other workspaces, including Pack Builder, fitting, asset browsing and project transfer, within reach. Learn opens guided help.

Use New project on Home or in Projects to choose one of the five project types. Existing work stays in the same library. Use the top-right Workspace settings control for preferences and updates, or press Ctrl+K to search commands.

Beginner exercises and backups are still on Home; scroll below Recent projects to find them. The command palette also retains Getting started as a route back to Home.

Choose a starting path#

  • New to the app? Follow Install on Windows, then Your first project.
  • Already use Brick by Script? Follow Update the app to choose the right update path for your installed version.
  • Interested in code? Start with Script Studio.
  • Bringing a design from another computer? Learn how to save and move your projects.

Read What’s new for the latest changes. You can keep using your existing project library after an application update.

Set up your workspace, or use an optional GitHub account to continue on another PC.

Know which version you are using#

The public download is 0.21.0 alpha. These guides cover that release, including Clothing, Jewelry and Vehicle studios. If you installed an older version, use the installation guide to update.

The app is still in alpha development. The installer is unsigned, and clean-device, laptop and owner-run in-game acceptance remain pending. A successful preview or export does not prove that a resource works in game. The export guide explains the steps between an editable design and a tested FiveM resource.
