Make the workspace yours

Use the Midnight Showroom settings sidebar to arrange panels, tune your editor and find recovery, tools and cloud projects.

Open workspace settings#

Choose the top-right Workspace settings control. The Midnight Showroom sidebar groups controls into Workspace, Editor, Recovery, Tools and Account & cloud, with App updates below. Choose a category, then use Done or Return to project when finished.

These are preferences for this computer. Signing in does not copy your layout, tool installations or local settings to another PC. Changes save automatically; the footer remains reachable while the content scrolls in smaller windows.

Arrange the workspace#

In Workspace, show or hide Explorer, Inspector and the Bottom panel. The workspace preview reflects those switches and shows source text from the current project. Use MLO properties → Left / Right to choose the side for that studio’s properties panel.

Reset layout restores the layout defaults. It does not remove your projects.

Set up the editor and shortcuts#

Choose an editor font size, wrap long lines and decide whether to autosave edits. The Editor tab also contains MLO transform shortcut assignments. Assigning a key that another transform already uses swaps the two assignments.

With autosave off, save deliberately. When leaving unsaved work, read the Save / Discard / Cancel prompt. Recovery and Undo explains how those choices differ from checkpoints and backups.

Find recovery, tools and cloud#

  • Recovery: keep useful checkpoints and restore earlier work as a separate local project.
  • Tools: reopen workspace setup to review skill level, creative-tool paths and the default export folder.
  • Account & cloud: sign in with GitHub and explicitly save or download private project snapshots. Read Continue on another PC.
  • App updates: check releases, download and choose when to restart. Follow Update the app.

Expected result: close and reopen settings to find your chosen local preferences again. No account is required to customize the editor.
