Update the app

Check for new releases, download inside the app and choose when to install and restart.

Find the updater#

Open Workspace settings → App updates. You can also press Ctrl+K, search for App updates and select the command. The panel shows your installed version and selected update channel.

In-app installation is available for the registered Windows x64 setup installation. If you have a portable or development copy, the panel explains why installation is unavailable. Run the Windows setup installer to use this workflow. Versions before 0.18.0 need that manual installation once to gain the updater.

Check and download#

  1. Select Check for updates.
  2. If a newer compatible release appears, read its version and notes.
  3. Select Download update. Watch the progress or choose Keep working to return to your project while it downloads.
  4. Use Cancel download if you change your mind. You can download again later.

Expected result: the panel reports Your update is ready only after the downloaded file matches the published size and SHA-256. Checking and downloading do not install anything.

Install when you are ready#

  1. Save your work and keep a project backup before an upgrade.
  2. In App updates, choose Install and restart…, then confirm Install and restart.
  3. If the app asks about unsaved work, save it or cancel to keep working. The app finishes its close coordination before allowing the installer to replace application files.
  4. Wait for the app to reopen. Open App updates and confirm the installed version, then reopen your project.

The installer updates application files while your library remains in its existing profile. If installation or automatic restart fails, the next app launch can show the result. An unsigned alpha installer can still be blocked by Windows; keep the exact message for troubleshooting.

Choose when and what to check#

  • Check for updates when the app starts: an optional automatic check. Downloads and installation always wait for your action.
  • Include preview releases: includes alpha and other preview releases. This is enabled by default for the alpha app. Turn it off to look for stable releases only.

If no verified installer exists for your selected channel, the app tells you. A stable-only channel can have no eligible release while the product is in alpha.

If an update cannot finish#

Check your connection and free disk space, then select Check for updates or Retry download. GitHub may temporarily limit requests; try again later if that message appears. A cancelled or failed download does not replace your installed app, and incomplete downloads are cleaned up.

Keep your work saved before retrying an installation. If it continues to fail, use the official release page for the installer and report the exact message. SHA-256 checks protect download integrity; they do not replace publisher signing or a clean-device test.
