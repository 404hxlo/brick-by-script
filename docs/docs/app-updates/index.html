Update the app

Find your update path, download while you work and restart when you are ready.

Find the updater#

Open Workspace settings → App updates. You can also press Ctrl+K, search for App updates and select the command. The panel shows your Installed version and update channel.

  • 0.18.0 or later, installed with Windows setup: use the steps below. Open the installed app from the Windows Start menu.
  • 0.17.1 or earlier: the old app has no updater. Download the current Windows installer, save and close the older app, and install once. Future updates can use this panel.
  • Portable or development copy: the panel can check releases but cannot download or install them. Run the Windows setup installer to use in-app installation.
  • Custom workspace profile: installation is unavailable when the app was launched with a custom --user-data-dir. Open the installed app normally. Your custom profile is not moved or deleted.

See Install on Windows if you need help finding the installer or opening the installed copy.

Check and download#

  1. Select Check for updates. This needs an internet connection.
  2. If a newer compatible release appears, read its version and notes.
  3. Select Download update. Watch its progress, or choose Keep working to close the panel and continue editing while the download runs.
  4. Open App updates again, or select the update message in the bottom status bar, to return to its progress.

Expected result: Your update is ready appears only after the download matches the published size and SHA-256. Checking and downloading do not install anything.

If you see No newer updates found, you already have the newest compatible installer in the selected channel. You do not need to reinstall the same version.

Cancel a download or reopen later#

Keep working closes only the update panel; a running download continues. Cancel download stops it. Closing the whole app also stops an unfinished download.

Cancelled or interrupted downloads start again from the beginning when you retry; they do not resume from the previous percentage. Temporary partial files are cleaned up.

If you fully downloaded an update but closed the app before installing it, reopen App updates and select Check for updates, then Download update. The app can reuse a complete cached installer for the selected release after verifying it again. If the file is missing, changed or belongs to another release, it downloads the selected installer instead.

Install when you are ready#

  1. Keep a project backup before an upgrade.
  2. After the download is ready, choose Install and restart…. Read the confirmation, then select Install and restart. Choose Keep working to wait.
  3. If autosave is off and there are unsaved changes, choose Save changes to keep them, Discard changes only if you do not want them, or Cancel to keep the app open. If a creative-tool task is running, choose whether to keep working or cancel the task before closing.
  4. Wait for installation and the app to reopen. Check Installed version in App updates, then reopen your project.

The app finishes saving and closing before the installer replaces application files. Your library remains in its existing profile. The panel can show the last installation result; if reopening failed, launch Brick by Script from the Start menu and check that result.

Choose when and what to check#

  • Check for updates when the app starts: off by default. Turn it on to check after a supported installed copy starts. It only checks; downloads and installation still need your action.
  • Include preview releases: on by default for this alpha. The channel badge reads Stable + preview. Turn it off to use Stable updates only.

These choices are saved for the next time you open the app. If no verified installer exists for your channel, the app tells you. During alpha development, stable-only checks may have no eligible release. Enable preview releases if you want the published alpha updates.

If an update cannot finish#

What you seeWhat to do next
Connection, timeout or GitHub rate-limit messageCheck your connection. If GitHub is limiting requests, wait and try Check for updates later.
Download or integrity-check failureCheck available disk space, then choose Retry download. An unverified file is not offered for installation.
In-app installation unavailableRead the explanation in the panel. Open the registered installed copy with its normal profile, or use the official Windows setup installer.
Installation did not finishKeep your work saved, check the reported Windows exit code and retry. If it keeps failing, use the official installer and include that exact code in your issue report.
Windows blocks the installerKeep the exact message for troubleshooting. SHA-256 verification does not make this unsigned alpha signed or bypass Windows application controls.

The official release page has the installer and checksums. Follow Troubleshooting for reporting an issue. Core local editing does not require a successful update check.
