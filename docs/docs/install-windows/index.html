Install on Windows

Choose the published download, install the app and find the included examples.

Choose the published download#

Select Download Brick by Script for Windows to download the 0.16.6 installer directly. This is the current Windows x64 alpha prerelease. You do not need to find the file in a GitHub Assets list.

The release notes describe this version and its known limitations. The installer is unsigned, and clean-device and laptop acceptance remain pending. If Windows blocks the file, keep the exact message for troubleshooting; these instructions do not require disabling Windows security.

Install and open#

  1. Find Brick-by-Script-0.16.6-Setup.exe in your browser’s downloads or your Downloads folder.
  2. Open the installer and complete the installation, then launch Brick by Script.
  3. Open Getting started. Choose Open example house or Make a chat command to check that the workspace opens.

Expected result: the app opens an editable example or a guided practice project. You do not need Blender or a running FiveM server for this first check.

Keep your work when updating#

Close the app before running an upgrade installer. Save an editable project backup first, especially before switching builds or moving computers. An installer is separate from your project backup.

For another PC, transfer your project backups as well as the installer. If you use a portable app folder from a supplied bundle, keep its neighboring runtime files together; copying the executable by itself is not a complete portable installation.

The release provides SHA256SUMS.txt for checking downloaded file hashes. Use the hash for the exact filename and version you downloaded.
