Install on Windows

Install for the first time, update an older copy, or take your workspace to a laptop.

Choose the published download#

Select Download Brick by Script for Windows to download the 0.19.1 installer directly. This is the current Windows x64 alpha prerelease. You do not need to find the file in a GitHub Assets list.

The release notes describe this version and its known limitations. The installer is unsigned, and clean-device and laptop acceptance remain pending. If Windows blocks the file, keep the exact message for troubleshooting; these instructions do not require disabling Windows security.

Install and open#

  1. Find Brick-by-Script-0.19.1-Setup.exe in your browser’s downloads or your Downloads folder.
  2. Open the installer and complete the installation, then launch Brick by Script.
  3. Open Getting started. Choose Open example house or Make a chat command to check that the workspace opens.

Expected result: the app opens an editable example or a guided practice project. You do not need Blender or a running FiveM server for this first check.

Keep your work when updating#

Already on 0.18.0 or later? Open Workspace settings → App updates, or press Ctrl+K and choose App updates. Follow Update the app to check releases, download and choose when to restart.

On 0.17.1 or earlier? Download the current installer once to add the updater. Save your changes, create an editable project backup and close the older app before running it. After setup, launch Brick by Script from the Windows Start menu, then open Workspace settings → App updates to confirm the installed version.

For another PC, transfer your project backups as well as the installer. Portable folders and development copies cannot use in-app installation; use the Windows setup version. Keep portable runtime files together rather than copying only the executable. A copy launched with a custom workspace profile also cannot install in-app updates; open the installed app normally to use that flow.

The installer updates application files while the project library stays in its existing Windows profile. A project backup remains a separate copy of your editable work. The release provides SHA256SUMS.txt for checking manual downloads; in-app downloads verify the published file size and SHA-256. This verifies file integrity, not publisher signing.
