Edit real GTA clothing

Load a supported garment from your own game installation, place artwork on its UV layout and export the right result.

Choose the right source#

Clothing Studio is included in public alpha 0.16.6. Start with a supported garment and keep its original files before making changes.

A studio learning template is useful for practicing artwork. To edit actual GTA clothing, load a supported game garment and its real paint surface. The game files are not included with Brick by Script; use your own legally accessible GTA V Legacy installation or permitted source files.

Load a garment#

  1. Open a Clothing Studio design and choose Edit GTA clothing…. This opens the fitting controls beneath the preview.
  2. Use Browse GTA tops… to read compatible tops from your local installation. Choose the desired drawable and texture from the available choices, then load the selection.
  3. Wait for the original garment and paint surface to finish loading. Check Imported garment, Paint surface and the displayed character before adding artwork.
  4. For a file you already have, use Load reference GLB… or Import GTA components… as appropriate. A filename typed into an Open dialog does not create or download the model; choose a file that actually exists.

The right-hand panel should become Garment UV artwork. If it asks you to relink the garment, restore the source before treating the fitting view as current.

Place your artwork#

Choose Add text or Add PNG for artwork you have permission to use. Select the artwork layer and use Place on 3D model when you want to position it on the garment surface.

Enable UV seams to see how the flat texture wraps around the model. Keep artwork inside the intended UV region. Rotate the character and inspect the front, sides and back: a design that looks centered on the flat image can cross a seam or land on another part of the garment.

Export and continue#

Export PNG texture saves an image. The texture tools also provide Build texture YTD and Retexture existing YTD… for their supported texture-dictionary workflows. A texture does not contain the garment's mesh or rig.

For geometry or rig changes, choose Edit mesh in Blender…. Save your Blender edits and use Refresh from Blender to inspect the updated source. Pack Builder handles the relevant native component workflow; the finished wearable still needs in-game testing.

If the body pokes through the shirt, check that you loaded the intended garment and character combination. Enlarging artwork or changing fabric color cannot repair a mesh-fitting problem.
