Edit real GTA clothing

Set up a real male or female GTA character, choose a garment, place artwork and understand the steps to a native wearable.

Choose the right source#

Clothing Studio is included in public alpha 0.21.0. Start with a supported garment and keep its original files before making changes.

In 0.20.1, Clothing Studio leads with Set up GTA character instead of the old bundled fitting person. The setup prepares a real male or female freemode character from your own GTA V Legacy installation. You do not need to find a wearable GLB first.

Game models are not bundled with Brick by Script. The setup needs Blender with Sollumz and CodeWalker installed on your PC. Read Set up Blender and Sollumz before starting if these tools are not ready.

Set up your first GTA character#

  1. Create or open a clothing design. For the default top, choose Tops, T-shirts & hoodies under Item type.
  2. Choose Male or Female under Fitting body.
  3. Select Set up GTA character in the preview. On first use, choose your GTA V Legacy installation. If asked, locate CodeWalker from its complete installation.
  4. Wait while Studio reads the local game components and prepares the character through Blender/Sollumz. Check the displayed model and Paint surface before adding artwork.
  5. Save your project. Studio remembers the prepared character on this PC. A saved project created through this setup can restore that character automatically when reopened.

Each body is prepared on first use. In another new top design, select Set up GTA character to reuse the prepared body; the app does not silently replace an existing original garment or reinterpret its artwork. For jackets, dresses and other item types, use the matching GTA item browser to select the garment you actually want.

The character cache belongs to this app profile on this PC. It is not included in project backups, cloud snapshots or the public installer. On another computer, complete setup using that computer's game installation. If a setup-created project has no usable cache, select Load saved GTA character to prepare it again. A custom imported GLB still needs its own original file for relinking.

Without the game tools, select Work on an original garment without a character to continue with an original shirt or hoodie pattern. This shows the garment alone. Use a real GTA body later for game-specific fit checks.

Choose what you want to make#

Open Item type in Clothing Studio and select the category that matches your source:

  • Tops, T-shirts and hoodies; jackets and coats; dresses and full outfits.
  • Pants and jeans, shorts, skirts, shoes and sneakers, boots.
  • Hats and caps, helmets, glasses and sunglasses, goggles, masks and face coverings.
  • Gloves and arms, bags and backpacks, undershirts, vests and body armor, badges and decals, or a custom wearable target.

Studio shirt/hoodie patterns remain available for learning. Other categories require a matching imported source mesh. For example, choosing Hats & caps sets the relevant prop workflow; it does not turn a T-shirt into a hat. Arbitrary imported clothing still needs suitable skin weights and GTA material setup.

Manage artwork from a layer menu#

In 0.19.1, right-click an artwork layer to duplicate it, copy or paste artwork, raise or lower its order, show or hide it, or remove it. Unavailable actions are disabled. The same menu opens with Shift+F10 or the Menu key when a layer row is focused.

These actions edit the artwork layers of the design. Removing a layer does not remove the source garment. Use the studio’s Undo control to reverse an unintended edit during the session.

Load a garment#

  1. Select the intended Item type and fitting body. For the default top, use Set up GTA character. For another garment, choose Edit GTA clothing… to open the GTA item browser directly.
  2. If prompted, select your GTA V Legacy installation. Choose a compatible drawable and texture from the choices beneath the preview, then select Edit selected GTA top or Edit selected GTA item. The expandable Fit real GTA clothing panel also retains Browse GTA tops… and Browse GTA items….
  3. Wait for the actual model and paint surface to finish loading. Check Imported garment, Paint surface and the displayed character before adding artwork. The body, item type and browse controls temporarily pause during loading to prevent overlapping requests.
  4. For a source already on disk, use Load wearable GLB… or Import GTA components… as appropriate. Choose a file that exists; typing a suggested filename does not download it.

The right-hand panel should become Garment UV artwork. Imported custom clothing GLBs are not embedded as a complete retained source inside the project. Keep the original GLB available; a saved binding can ask you to relink it after reopening or moving PCs. Custom files are not silently substituted with the default character merely because their filenames match. Locally catalogued GTA items can reload from the configured game installation.

Change the body or item type#

  1. Choose another Fitting body or Item type. A Custom wearable also exposes its intended GTA wearable slot.
  2. If a garment or Blender source is linked, read Change garment or character?. Choose Cancel to keep the current design exactly as it is.
  3. Choose Change and keep artwork to detach the current garment, its original diffuse base texture and linked Blender source. Your source files stay on your computer; your added logos, text and other artwork stay in the project.
  4. Use Set up GTA character, Edit GTA clothing… or your own compatible source to choose the new garment. Review artwork placement on its UV layout before exporting.

Changing the target does not convert or refit the old geometry. A male shirt is not automatically made into a female shirt, and selecting a hat category does not turn it into a hat. The old preview is cleared so it cannot be mistaken for the newly selected target.

Use Undo or Ctrl+Z to restore the previous design and source binding during the session. Recognized local GTA sources can restore their preview; a custom imported GLB may ask you to relink its original file. These controls are temporarily disabled while a model is loading.

Place your artwork#

Choose Add text or Add PNG for artwork you have permission to use. Select the artwork layer and use Place on 3D model when you want to position it on the garment surface.

Enable UV seams to see how the flat texture wraps around the model. Keep artwork inside the intended UV region. Rotate the character and inspect the front, sides and back: a design that looks centered on the flat image can cross a seam or land on another part of the garment.

Reuse an artwork layer#

  1. Select a text or PNG layer in Artwork layers.
  2. Choose Duplicate to make an independent layer at the same position, then move or edit that copy.
  3. Choose Copy layer, open another clothing project, and choose Paste layer to reuse it there.

The copied layer keeps its text or embedded PNG, size, position, rotation, opacity and mirroring. This is a local clipboard inside the running app, not the Windows clipboard or a saved preset library. Ctrl+C / Ctrl+V use it when the clothing workspace is focused; typing fields keep ordinary text-copy behavior.

Clothing Undo / Redo survives switching workspaces in the current session. Reopening the app starts a new Undo history; save or checkpoint work you want to keep. The design still has one artwork stack and selected paint material, not independent artwork stacks for every material.

Apply a saved fit without losing newer edits#

In Fitting, choose a supported saved GTA garment and save any current source-design edits before applying its fit. In 0.19.3, completion keeps newer unsaved script or design edits made while the fit save was running. The saved fit and project revision are reconciled without reloading an older editor snapshot.

If you independently change the source or fit, those newer changes remain yours. Save again when the project still shows unsaved work. Recheck the fit on the intended character and validate the final native resource in FiveM.

Export and continue#

Export PNG texture saves an image. The texture tools also provide Build texture YTD and Retexture existing YTD… for their supported texture-dictionary workflows. A texture does not contain the garment's mesh or rig.

For geometry or rig changes, choose Edit mesh in Blender…. Save your Blender edits and use Refresh from Blender to inspect the updated source. Pack Builder handles the relevant native component workflow; the finished wearable still needs in-game testing.

If the body pokes through the shirt, check that you loaded the intended garment and character combination. Enlarging artwork or changing fabric color cannot repair a mesh-fitting problem.
