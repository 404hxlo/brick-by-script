Creator glossary

Plain-language definitions for the terms you will encounter across the studios.

Projects and code#

  • Project: the editable work stored by Brick by Script. Keep a backup if you want to restore or move it.
  • Resource: a named folder that FiveM can start and stop.
  • Manifest: the fxmanifest.lua file that declares a resource’s scripts, files and other information.
  • Client and server: the player’s game and the server process. Lua code must run on the side where its required functions and data exist.
  • NUI: a web-based interface displayed by the game, such as a menu or HUD.

Models and materials#

  • Mesh: a model’s connected geometry. Vertices are points, edges connect points, and faces form surfaces.
  • Normal: a direction associated with a face or vertex, used in shading and surface orientation.
  • UV layout: a mapping from a model’s surface to a flat texture. Place artwork on the correct UV area to make it appear on the intended part.
  • Material: settings that control a surface’s appearance. A texture is an image used by a material.
  • Rig and skin weights: bones and their influence on mesh vertices. They help an accessory or garment move with a character.
  • GLB: a common model exchange format. It is useful for supported imports and source exports, but is not itself a native GTA drawable.

Interiors and performance#

  • Collision: geometry that determines where the player or another object can physically move.
  • MLO room: an interior room definition used by the game, separate from the visible wall geometry.
  • Portal: a visibility connection between rooms or between a room and the exterior. A visible doorway and a portal are different things.
  • Archetype: a reusable asset definition. Placement data refers to that definition when putting an instance in the world.
  • LOD: level of detail; alternate detail levels can reduce rendering work at a distance.
  • Draw call: a rendering request. Editor counts and memory estimates help investigate complexity, but are not measured in-game FPS.

Build status#

Source export means editable output for another tool. Native conversion means producing the required game-format files. Packaging gathers the required files into a resource. In-game validation checks the result in an actual FiveM session. Learn how these stages fit together in From project to FiveM resource.
