Troubleshoot your first problem

Find the failing stage, make a small correction and check the result without losing your project.

Identify the failing step#

Write down what you were trying to do and the exact message. Was the failure during installation, opening a project, importing a model, exporting, or running the resource in FiveM? Fix the first failed stage before continuing to the next.

Check your app version against the guide’s label. These guides describe public alpha 0.19.0. Update an older installation before looking for controls added in later releases.

Save a project backup before experimenting with major changes. When reporting a problem, share the version, reproduction steps and a useful screenshot. Review logs before sharing them and remove credentials or unrelated personal information.

A file is missing or validation fails#

  • Manifest error: compare the declared path with the actual file, including its folder, spelling and capitalization. A file named client/main.lua needs a matching declaration.
  • Import dialog says “File not found”: select a file that exists on disk. Typing a suggested model filename does not create or download it.
  • Missing textures or linked assets: restore the expected files, check the project’s dependency information and prepare a complete transfer when changing PCs.
  • Export is blocked: open the problem list, fix the reported errors and validate again. An output filename is not a completed export.

A project is missing, Trash is blocked or Undo changed#

  • Missing from the library: clear search, type, folder and Favorites filters. Then check the Trash tab.
  • Cannot move to Trash: read the named collection or server-job dependency, remove that reference and retry.
  • Cannot duplicate: check linked source files and the selected Blender installation. A duplicate with linked sources needs independent packed copies.
  • Cannot pin a checkpoint: unpin an older point or save a separate backup. Existing pinned history is kept when a pin limit is reached.
  • Undo unavailable after reopening: creator Undo is session history, not saved project history. Use the saved design, a recovery point or a backup.
  • Discard says the project changed: a newer edit arrived while the operation was waiting. It was kept; review the current design before retrying.

Follow Recover work and use Undo for the complete steps.

A model or native build is not right#

First confirm the imported model and its scale, orientation, materials and references. A fitting preview is not a guarantee of finished rigging. For native builds, check that the required tools and compatible workflow are available before changing the geometry.

In setup, Check installed tools inspects the selected Blender/Sollumz workflow. Choose blender.exe and Choose CodeWalker let you select the intended installations. Tool detection alone does not verify game compatibility.

Use help, then report a reproducible issue#

Open Getting started → Why is this broken? for the practice repair workflow, or Search help and documentation to find an explanation and an official reference.

If the problem remains, use the GitHub issue tracker. Include the smallest set of steps that reproduces it and say whether the failure happens in the app or in FiveM. Do not attach someone else’s protected model files just to demonstrate a bug.
