Tools, downloads and character models

Find official tool downloads and prepare real male/female GTA references from your own game.

Only set up what your workflow needs#

Open Learn → Tools & models or Tools → Tools & models in the app. Filter by studio, search for a tool and open the reviewed source page. Links open in your browser; the app does not automatically install tools.

Lua lessons, Script Builder, NUI Designer, original scene editing and artwork practice do not need downloaded character models. Native asset workflows need compatible installed tools. Use Check installed tools / choose installations to inspect the selected Blender, Sollumz and CodeWalker setup.

Male and female GTA character models#

The supported local setup prepares real mp_m_freemode_01 or mp_f_freemode_01 references from your own GTA V Legacy installation. There is no separate character GLB download to hunt for.

  1. Set up Blender with Sollumz and select CodeWalker.
  2. In Clothing Studio, select Male or Female under Fitting body, then Set up GTA character for tops. For other categories, use Edit GTA clothing.
  3. In Jewelry Studio, choose the matching fitting body. Use Fitting reference → Load from GTA installation in the pattern editor, or Load GTA fitting body for imported jewelry.
  4. When prompted, choose the Legacy folder containing GTA5.exe and x64v.rpf. Inspect the body and fit before editing.

The generated reference stays on this PC. Repeat setup on another PC; caches are not included in public installers or project backups. A body reference does not automatically rig arbitrary clothing or jewelry. Game models are not redistributed with the app.

Blender#

Free tool — Required by the automated model conversion and source-building workflows. Not needed to read lessons or edit Lua.

  1. Download a Windows version supported by your Sollumz release; the newest Blender release is not automatically compatible.
  2. Install and open Blender once. Then install Sollumz inside that same Blender installation.
  3. Use Check installed tools below and choose that blender.exe if the app detects a different installation.

Official Blender downloads and LTS versions

Sollumz#

Free Blender extension — Adds GTA asset support to Blender. Native import/export availability depends on the installed release/provider; use the app’s actual tool check.

  1. Follow the official installation guide for your Blender version.
  2. For Blender 4.2+, the guide documents adding https://repo.sollumz.org/ in Preferences → Get Extensions → Repositories. Choose the stable Sollumz extension.
  3. Enable it, then return to Brick by Script and check the same Blender installation. Read the reported native-workflow status before building.

CodeWalker#

Free external tool — Used to read local GTA assets, inspect native files and support conversion workflows.

  1. Start at the developer’s project page and follow its published download route. Extract the complete tool folder.
  2. Keep CodeWalker.exe with its accompanying files. A repository source ZIP is not a compiled installation.
  3. In Check installed tools, choose CodeWalker from that folder. Point game browsing at your compatible GTA V Legacy installation.

GTA V Legacy and local game assets#

Owned game required for game imports — Provides the male/female freemode bodies, stock clothing, accessories and donor vehicles used by local-game workflows. Original scene editing does not require downloading these assets.

  1. Install your owned GTA V Legacy copy through its official launcher or storefront. The local import workflows in this app require Legacy data.
  2. When prompted, browse to the folder containing GTA5.exe and x64v.rpf. Do not select the launcher executable or a shortcut.
  3. Use the character instructions below. No separate male/female GLB download is needed for the supported local setup. Keep game files local; they are not included in the public app or project backups.

FiveM client#

Needed for in-game testing — Used to test the exported resource in the actual game. An editor preview is not this test.

  1. Follow the official client installation guide and its current game requirements.
  2. Join your dedicated development server after installing the test resource.
  3. Run the lesson’s in-game checklist. Record anything you have not tested as not tested.

Official FiveM installation and client download guide

FXServer and a development server#

Needed for resource testing — Runs resources for a FiveM client. Use a separate test environment; lessons do not deploy anything automatically.

  1. Follow the official server setup guide, which links the appropriate server artifacts and setup requirements.
  2. Configure a dedicated local test server and install only the resource you intend to test.
  3. Read server/client logs and repeat the same checks after a fix. Keep backups of your editable project outside the deployed resource.

Official FiveM server setup and downloads

Compatibility and source checks#

External references were checked November 17, 2026. Follow the selected release’s compatibility notes; the newest Blender is not automatically compatible with your Sollumz release.
