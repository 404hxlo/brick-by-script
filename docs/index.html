BEFORE YOUR FIRST BUILD.

Good questions.

Here’s what to expect when you get started.

Do I need to know how to code?

You can start with visual room editing, clothing artwork, jewelry workflows and guided projects. Scripting tools are there when you want to write or customize Lua.

Do I need Blender or CodeWalker?

Not to explore the core editors and examples. Advanced modeling and supported native GTA asset exports use Blender with Sollumz, and some workflows require CodeWalker. The app’s build tools explain the dependencies for the selected workflow.

Are GTA models and clothing included?

No copyrighted GTA V assets are bundled. Included learning examples use original geometry. To work on real game clothing or vehicles, you need your own legally accessible files and the supported import tools. An ordinary GLB model still needs the appropriate game setup and rigging.

Can I make hats, shoes, watches and other accessories?

Clothing Studio has item categories for clothing and props, including hats, glasses, goggles, pants and shoes. Start those categories with a permitted GTA item or compatible imported mesh. Jewelry Studio adds editable watches, bracelets, rings, grills and earrings, plus supported imports. Fit and inspect the source, then follow its supported native workflow and test it in FiveM. Choosing a category alone does not model or rig a custom item.

Can I recover a project or try a different version?

Yes. Use Duplicate in the Project library to make an independent design copy. Move unwanted projects to recoverable Trash, or name and pin checkpoints before important edits. Clothing and jewelry Undo follows you between workspaces during the current app session. Keep a separate project backup for long-term protection.

How do I update without leaving the app?

In version 0.18.0 or later, open Workspace settings → App updates. Check for a release, read its notes and download it while you work. Choose Install and restart when ready; canceling the save prompt keeps the app open. Older versions need one manual installation to gain the updater. Read the update guide →

Can I use my work in FiveM?

Supported build workflows prepare native assets and resources. A PNG, GLB or Blender source file alone is not a finished FiveM resource. Check dependencies, conversion results and the exported files, then test the resource in a development server. An editor preview does not prove in-game compatibility.

Is the app finished? Is it free?

Brick by Script is in alpha development. The public alpha is available to download at no charge; future pricing has not been announced. The screenshots show version 0.16.6. Read the release notes before installing.

Can I work offline and move to another PC?

Core local editing works offline without an account. Optional GitHub sign-in lets you save private cloud snapshots and restore a separate copy on another PC. Uploads are explicit, not automatic sync, with a preview allowance of 512 MiB of reserved snapshot storage including older versions. Project backup and transfer files also work without cloud.
